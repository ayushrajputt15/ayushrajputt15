## 💻 Featured Development Projects

### ⚡ AI-Powered Dynamic Pricing Engine (Event-Driven Microservices)
🔗 [GitHub Repo](https://github.com/ayushrajputt15/event-driven-dynamic-pricing-system)

- Engineered an event-driven polyglot system (Spring Boot, Python Flask, React, MySQL) powered by **Apache Kafka** for async event ingestion to adjust e-commerce product prices in real-time based on demand.
- Integrated an asynchronous **sales velocity pricing algorithm** with a background thread cool-down decay loop (25% velocity decrease every 2s) and database self-correction.
- Designed a resilient fallback client in **Spring Boot** using property-based toggle switches to route pricing updates if local Kafka brokers are offline, guaranteeing zero-downtime.
- Secured REST endpoints using **Spring Security and JWT tokens** (BCrypt password hashing) to expose CRUD endpoints and price history catalogs.
